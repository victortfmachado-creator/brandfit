# BrandFit

Ferramenta de inteligência de marca no PDV (trade marketing, padrão Ambev).

**Acesse:** https://victortfmachado-creator.github.io/brandfit/

Protótipo autocontido (motor + UI em 3 arquivos JS, sem dependências externas).
Base mock de 36 PDVs gerada localmente; alimenta-se de base real via URL JSON/CSV ou import (aba Config · Motor).

v1.3 — marca-alvo dinâmica por PDV, motor autônomo, métricas CMO (prêmio de valor, equity), alertas do gerente.
